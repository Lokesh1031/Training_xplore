Media Queries
-------------

    div{
        background:pink;
    }
 }

    }
 }


Positions
---------
static - default position (the top,bootm,left and z-index properties have no effect)
relative -elelment is to itself
absolute - position relative to its closest position ancestor
fixed - positioned relative to browser
sticky - positioned based on users scroll position
